# Sec-CH-Lemon Tap

## How do I install these formulae?

`brew install sec-ch-lemon/tap/<formula>`

Or `brew tap sec-ch-lemon/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "sec-ch-lemon/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
